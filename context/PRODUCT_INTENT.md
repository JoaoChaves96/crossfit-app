# Product Intent

## Product

A CrossFit gym class booking application.

## Primary User

Athlete (gym member).

## Core Problems Solved

- Athletes can:
  - see upcoming classes
  - view class details
  - book a class or join a waitlist
  - see their bookings
  - cancel a booking

## Secondary Users (Later)

- Coach
- Gym owner

## Explicit Non-Goals (for MVP)

- Payments
- Class programming creation
- Attendance tracking
- Results tracking
- Notifications
- Production authentication flows

## Success Criteria (MVP)

An athlete can:

1. Open the app
2. Select a gym
3. See available classes
4. Book a class
5. See booking reflected everywhere
6. Cancel the booking

Without errors, confusion, or manual intervention.

## Platform

- Mobile (iOS / Android)
- Web (browser)

## Current Status

Athlete MVP flow implemented and runnable locally.
